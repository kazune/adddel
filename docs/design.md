# adddel 要件定義

## 1. 概要

任意の2つのファイルを比較し、追加行数（additions）と削除行数（deletions）を集計する Bash スクリプト。

差分の詳細は表示せず、集計結果のみを標準出力に出力する。

引数解析、集計条件、エラー処理、テストの詳細は [契約](contract.md) に定める。

## 2. 機能要件

### 入力

- 比較対象の2ファイルをコマンドライン引数で指定する。
- 第1引数を変更前、第2引数を変更後のファイルとする。
- Gitリポジトリ外のファイルにも対応する。

### 差分集計

- 追加行数と削除行数を集計する。
- 既存行の変更は、削除と追加として数える。
- 空白や空行の変更も差分として扱う。
- 差分が存在しない場合、両方とも `0` とする。

### 出力

通常モード

半角スペース1文字（`0x20`）区切りの2列、1行で出力する。

```
12 5
```

- 1列目：additions
- 2列目：deletions

labelモード（`-l`, `--label`）

```
additions: 12, deletions: 5
```

## 3. コマンドライン仕様

| コマンド                                    | 動作      |
| --------------------------------------- | ------- |
| `adddel old.txt new.txt`         | 通常出力    |
| `adddel -l old.txt new.txt`      | ラベル付き出力 |
| `adddel --label old.txt new.txt` | ラベル付き出力 |
| `adddel -h`                      | ヘルプ表示   |
| `adddel --help`                  | ヘルプ表示   |
| `adddel --version`               | バージョン表示 |

## 4. 終了ステータス

| 状態         | 終了コード  |
| ---------- | ------ |
| 差分なし・正常終了  | `0`    |
| 差分あり・正常終了  | `0`    |
| 引数不正       | `2` |
| ファイルが存在しない | `2` |
| ファイル読み取り失敗 | `2` |
| 通常ファイル以外・バイナリで行数集計不能 | `2` |
| Git未導入・差分集計失敗 | `1` |
| ヘルプ・バージョン表示 | `0` |

差分の存在はエラーとみなさない。

エラーメッセージは標準エラー出力（stderr）に出力する。
エラー時は標準出力を空にし、英語のメッセージを `adddel: 理由` の形式で出す。

## 5. 実装方針

- Bashで実装する。
- macOS・Linux、Bash 3.2以上、Git 2系を対象とする。
- 原本は `src/adddel` と `src/adddel.1.md` に配置する。
- `make dist` でGitからバージョンとUTCのコミット日付を取得し、`dist/bin/adddel` と `dist/share/man/man1/adddel.1` を生成する。
- manページはPandocで変換する。
- タグ以降のコミットにはコミットIDを付け、追跡ファイルに変更がある場合はさらに `-dirty` を付ける。
- `--version` は生成時に埋め込んだバージョンを表示する。
- CLIと生成処理のBatsテストは `tests/` に配置する。
- 差分の集計には `git diff --no-index --numstat` を使用する。
- myersに固定し、indent heuristic・外部diff・textconv・リネーム検出を無効にする。
- ファイル名を安全に扱うため、Gitの出力は `-z` 形式で取得する。
- `--numstat` の第1列・第2列を取得する。
- Gitの終了コード `1`（差分あり）は正常として扱う。
- 集計列が `-` となるバイナリはエラー扱いにする。
- 同一内容のバイナリでGitの出力が空なら、追加・削除ともに `0` とする。
- `.gitattributes` によるテキスト／バイナリ判定の影響を許容する。
- Gitリポジトリの存在は要求しない。

## 6. 非対応機能

スクリプトをシンプルに保つため、以下は実装しない。

- 差分の詳細表示
- 変更ブロック数の集計
- 変更率の計算
- ディレクトリ単位の比較
- 空白・空行を無視するオプション
- JSON出力

設計方針： 2ファイルを比較し、追加・削除行数を1行で返すことだけに特化した、パイプラインで利用しやすいCLIツールとする。
