# adddel 契約

## 位置づけ

この文書は `docs/design.md` に基づき、adddel の外部仕様と実装時に守る条件を定める。
未確定の仕様は「要確認」として記載し、実装前に確定する。

## 入力と引数

- 比較対象のファイルを2つ指定する。
- 第1のファイル引数を変更前、第2のファイル引数を変更後として扱う。
- Gitリポジトリ外のファイルも比較できる。
- ディレクトリ単位の比較には対応しない。
- バイナリファイルは集計対象外とし、エラーとして扱う。

| 呼び出し | 動作 |
| --- | --- |
| `adddel old.txt new.txt` | 通常モードで集計結果を出力する。 |
| `adddel -l old.txt new.txt` | ラベル付きで集計結果を出力する。 |
| `adddel --label old.txt new.txt` | ラベル付きで集計結果を出力する。 |
| `adddel -h` | ヘルプを表示する。 |
| `adddel --help` | ヘルプを表示する。 |

ラベル付き出力の長いオプション名は `--label` とする。

## 集計アルゴリズムと不変条件

- Bashで実装する。
- 差分の集計には `git diff --no-index --numstat` を使用する。
- `--numstat` の第1列を追加行数、第2列を削除行数として取得する。
- 既存行の変更は、削除と追加として数える。
- 空白や空行の変更も差分として扱う。
- 差分が存在しない場合は、追加行数と削除行数をともに `0` とする。
- Gitの終了コード `1` は差分の存在を表すため、正常として扱う。
- 差分の詳細は表示せず、集計結果のみを標準出力に出力する。

## 出力形式

### 通常モード

追加行数、タブ文字、削除行数の順に、2列を1行で出力する。
次の例の `\t` は実際のタブ文字を表す。

```text
12\t5
```

### ラベル付きモード

`-l` または `--label` を指定した場合、次の形式で集計結果を出力する。

```text
additions: 12, deletions: 5
```

## エラー処理と終了コード

| 状態 | 終了コード | 出力 |
| --- | --- | --- |
| 差分なしで集計成功 | `0` | 標準出力に集計結果を出力する。 |
| 差分ありで集計成功 | `0` | 標準出力に集計結果を出力する。 |
| 引数不正 | `0` 以外 | 標準エラー出力にエラーメッセージを出力する。 |
| ファイルが存在しない | `0` 以外 | 標準エラー出力にエラーメッセージを出力する。 |
| ファイル読み取り失敗 | `0` 以外 | 標準エラー出力にエラーメッセージを出力する。 |
| バイナリファイル | `0` 以外 | 標準エラー出力にエラーメッセージを出力する。 |
| 差分集計失敗 | `0` 以外 | 標準エラー出力にエラーメッセージを出力する。 |

差分の存在そのものはエラーとみなさない。

## 互換性と対象外

Gitリポジトリの存在は要求しない。
次の機能には対応しない。

- 差分の詳細表示
- 変更ブロック数の集計
- 変更率の計算
- ディレクトリ単位の比較
- 空白・空行を無視するオプション
- JSON出力

## 実装前の要確認事項

| 項目 | 未確定の内容 |
| --- | --- |
| 引数の解析 | オプションの指定位置、重複指定、未知のオプション、`--` の扱いを定める。 |
| ヘルプ | 本文、出力先、終了コード、他の引数と併用した場合の動作を定める。 |
| ファイルの検証 | シンボリックリンク、特殊ファイル、同一ファイル指定の扱いを定める。 |
| パス名 | 空白、タブ、改行、先頭のハイフンを含むパスの受け付け方と解析方法を定める。 |
| テキストの境界条件 | 空ファイル、末尾改行の有無、LFとCRLF、文字コードの扱いを定める。 |
| バイナリ判定 | 判定方法と、同一のバイナリファイルにも適用する検証方法を定める。 |
| Git出力の検証 | 差分なしで出力が空の場合の処理、および列不足や数値以外の値の扱いを定める。 |
| Gitの設定 | ユーザー設定や属性による差分集計への影響を許容するか定める。 |
| 実行環境 | 対象OS、BashとGitの対応バージョン、Gitが利用できない場合の処理を定める。 |
| エラーの詳細 | エラー別の終了コード、メッセージの文面、失敗時の標準出力の扱いを定める。 |
| 出力の終端 | 集計結果の行末改行の有無を定める。 |
| 実装ファイル | スクリプトとテストの配置先、および実行方法を定める。 |

## 必要なテスト

### 正常系

- 追加のみの入力で追加行数と削除行数が正しいこと。
- 削除のみの入力で追加行数と削除行数が正しいこと。
- 行の変更が削除と追加として集計されること。
- 差分のない入力で両方の集計値が `0` となること。
- 空白や空行の変更が集計されること。
- 通常モードの列順、タブ区切り、1行の出力が契約と一致すること。
- `-l` と `--label` の出力がラベル付きの形式と一致すること。
- Gitリポジトリ外のファイルを比較できること。

### 異常系

- 引数不正で非ゼロ終了し、標準エラー出力にメッセージを出力すること。
- 存在しないファイルで非ゼロ終了し、標準エラー出力にメッセージを出力すること。
- 読み取りに失敗した場合に非ゼロ終了し、標準エラー出力にメッセージを出力すること。
- バイナリファイルで非ゼロ終了し、標準エラー出力にメッセージを出力すること。
- 差分集計に失敗した場合に非ゼロ終了し、標準エラー出力にメッセージを出力すること。

### 境界値と回帰

- Gitが終了コード `1` を返す差分ありの入力でも、adddelは `0` で終了すること。
- 差分の詳細が標準出力に混入しないこと。
- 空ファイル、末尾改行、改行コード、特殊なパス名のテストは、要確認事項の確定後に期待値を定める。
- オプション解析、ヘルプ、ファイル検証、実行環境のテストは、要確認事項の確定後に追加する。
